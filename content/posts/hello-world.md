This is the first post of this blog. The idea is simple: every time I study something, I'll try to write about it here.

## Why write in public?

When I only read about a topic, it's easy to *feel* like I understood it. Writing it down for someone else exposes every gap. If I can't explain it, I don't know it yet.

## Why in English?

Because I also want to improve my English. Writing forces me to think about every word, which turns each post into two lessons at once.
